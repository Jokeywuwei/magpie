[6] Release procedure (not executed)
------------------------------------
1. Review and commit exactly the tracked modifications and untracked
   source files in [1] and [2] on a release commit; exclude [3].
2. Add to .dockerignore: .mimosa, **/.mimosa, docs, magpie, dist, build,
   site, .git, .github, *.md. Keep internal/ (go:embed needs its assets).
3. Build only from the clean tag:
     make cli VERSION="$(git describe --tags --always --dirty)"
     # or
     docker build --build-arg VERSION="$VERSION" -t minirelay:$VERSION .
   Refuse the build if `git status --porcelain` is non-empty.
4. Pin the toolchain image to golang:1.26.8-alpine (the Dockerfile today
   says golang:1.26-alpine) and record:
   - commit SHA, tag, tree hash
   - Go version (go.mod says 1.26.8)
   - binary SHA-256 and image digest
   - SBOM / build attestation
5. Smoke the image: /portal/ 200, registration closed, `magpie user add`
   creates the first admin, a user key calls /v1/models and a model.
6. The image CMD is "serve" (gateway only). A portal deployment must
   override it with `web --addr 0.0.0.0:3430 --no-open`.
7. Never tag or publish a build whose `git describe` contains -dirty.
